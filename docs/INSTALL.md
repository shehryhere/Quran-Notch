# Installing Quran Notch

## Download and install

The DMG is not currently available on GitHub Releases.

1. Visit the [Releases page](https://github.com/shehryhere/Quran-Notch/releases).
2. Download the latest official `.dmg` release asset when available.
3. Double-click the `.dmg` to mount it.
4. Copy **Quran Notch.app** into **Applications**, following the layout of the DMG.
5. Open the app from Applications and look for its menu bar interface.

## If macOS prevents the app from opening

Only continue if you downloaded the app from the official repository and trust the file.

If macOS blocks an unnotarized app, try opening it once, then go to **System Settings → Privacy & Security** and look for **Open Anyway** for Quran Notch. Confirm the prompt only if you trust the app. Steps may vary by macOS version.

Do **not** disable Gatekeeper globally.

## Daily verse changes

The app is intended to change its daily verse. The exact local-midnight transition still needs verification on the released build.

## Troubleshooting

If the app isn't visible, check the menu bar and its hidden icons; try launching it again from Applications. For bug reports, provide your macOS version, app version, and reproduction steps without sharing private information.
